sSummarizer

AI-powered web content summarization

AI Productivity Original Manifest V3
View on GitHub

Overview

sSummarizer (Simple Summarizer) is an AI-powered Chrome extension that transforms long articles and YouTube videos into concise, easy-to-digest summaries. Whether you're researching, learning, or just trying to save time, sSummarizer helps you quickly understand the key points of any web content.

The extension supports multiple AI providers including OpenAI (GPT models), Anthropic (Claude), and any compatible API endpoint. It features a beautiful floating window interface with real-time streaming responses, so you can watch the summary being generated live.

For YouTube videos, sSummarizer automatically extracts transcripts and summarizes the video content without needing to watch the entire video. The floating window is draggable and resizable, with adjustable font sizes for better readability.

Key Features

  • Multi-Provider AI Support: Connect to OpenAI, Anthropic, Gemini, Groq, Azure, and more
  • YouTube Intelligence: Automatic transcript extraction with timestamp support and subtitle preferences
  • Reddit Optimization: Summarize entire threads with customizable comment depth and sorting logic
  • Context Menu Integration: Highlight any text and summarize it instantly via the right-click menu
  • Real-Time Streaming: Watch summaries generate in real-time with a smooth, responsive interface
  • Floating Window Interface: Draggable and resizable summary display with font size controls
  • Debug Mode: Inspect extracted content to understand the data being sent to the AI
  • Security & Privacy: Content sanitization and local storage of API keys
  • Performance Optimized: Efficient extraction with auto-truncation for oversized content

Supported AI Providers

sSummarizer works with any OpenAI-compatible API endpoint:

  • OpenAI: GPT-3.5-Turbo, GPT-4, GPT-4-Turbo
  • Anthropic: Claude models via compatible endpoints
  • Custom APIs: Any service that implements the OpenAI chat completions format
  • Local Models: Self-hosted AI models with compatible APIs

Configure your API endpoint, key, and model in the extension options page. The extension includes a connection tester to verify your settings work correctly.

Installation & Setup

Option 1: Chrome Web Store (Coming Soon)

This extension will be available on the Chrome Web Store soon. Check back for updates!

Option 2: Install from Source (Developer Mode)

  1. Download or clone the repository from GitHub
  2. Open Chrome and navigate to chrome://extensions/
  3. Enable "Developer mode" using the toggle in the top right corner
  4. Click "Load unpacked"
  5. Select the directory where you downloaded/cloned the extension
  6. Click the extension icon and select "Options" to configure your API settings

Configuration

  1. API Endpoint URL: Enter your AI service endpoint (e.g., https://api.openai.com/v1/chat/completions)
  2. API Key: Your authentication key from the AI provider
  3. Model Name: Specify which model to use (e.g., gpt-3.5-turbo, gpt-4)
  4. System Prompt (Optional): Custom instructions for the AI to follow
  5. Click "Test Connection" to verify your settings
  6. Click "Save" to store your configuration

How to Use

For Web Pages: Navigate to any webpage and click the extension icon. The extension will extract the text content and generate a summary in a floating window.

For YouTube Videos: Open any YouTube video page and click the extension icon. sSummarizer will extract the video's auto-generated transcript and create a summary.

Window Controls: Drag the title bar to move the window, use A⁺/A⁻ buttons to adjust font size, click − to minimize, or × to close.
